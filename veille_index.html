Qu'est-ce que l'Edge Computing ?

L'Edge Computing est un système permettant de traiter les données directement sur les capteurs, les machines ou des micro-serveurs locaux plutôt que de tout envoyer sur un cloud distant, afin d'éviter la saturation des réseaux et de réduire drastiquement la latence.

Outils et Plateformes clés de l'Edge

  • Kubernetes Edge (K3s) : Conteneurisation légère pour orchestrer des applications sur des boîtiers distants.
  • TinyML : Modèles d'intelligence artificielle optimisés pour tourner sur des micro-contrôleurs à très basse consommation.
  • Passerelles Industrielles : Matériels robustes permettant le filtrage local des flux de données avant remontée cloud.
