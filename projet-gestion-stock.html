PROJET PPE (ÉCOLE) • 2026

Application de Gestion de Stock

Logiciel lourd de gestion logistique développé en Java et MySQL.

Contexte & Présentation

Dans le cadre des Projets Personnels Encadrés (PPE) du BTS SIO SLAM, nous avons conçu une application lourde destinée à optimiser la chaîne d'approvisionnement et la gestion d'un entrepôt logistique.

Objectifs & Fonctionnalités

  • Gestion des articles : Ajout, modification et suppression des produits en stock avec génération de références uniques.
  • Entrées/Sorties : Suivi automatisé des flux de marchandises en temps réel.
  • Alertes de réapprovisionnement : Notification automatique dès qu'un produit franchit le seuil critique minimal.
  • Gestion des fournisseurs : Liaison entre les articles et les fiches contacts fournisseurs.

Technologies & Organisation

  • Langage : Java (Interface graphique Swing / JavaFX).
  • Base de données : MySQL gérée avec JDBC pour les requêtes SQL.
  • Gestion de version : Git & GitHub pour le suivi du code.
  • Méthodologie : Travail en binôme suivant les principes de la gestion de projet Agile.

Bilan du Projet

Ce projet académique a permis de valider la maîtrise de la programmation orientée objet en Java, la modélisation de bases de données relationnelles ainsi que la gestion de requêtes sécurisées.
